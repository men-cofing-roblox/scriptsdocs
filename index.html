Quickstart

Get up and running with the API in a few simple steps. You'll need an API key and a modern JavaScript environment.

Tip Keep your API key on the server. Never expose secret keys in browser-side code.

1. Install the SDK

npm install @example/docs

2. Create a client

import { Docs } from "@example/docs";

const docs = new Docs({
  apiKey: process.env.DOCS_API_KEY
});

3. Make a request

const page = await docs.pages.create({
  title: "Hello, world!",
  published: true
});

console.log(page.url);

Installation

The SDK works with Node.js 18+ and most modern server frameworks. 

# npm
npm install @example/docs

# pnpm
pnpm add @example/docs

# yarn
yarn add @example/docs

Authentication

Authenticate requests using your API key in the Authorization header. 

Authorization: Bearer YOUR_API_KEY

Errors

Errors use conventional HTTP status codes and include a machine-readable error code.

Status Meaning Action
400 Invalid request Check parameters
401 Unauthorized Check your API key
404 Not found Check the resource ID
429 Rate limited Retry with backoff

Webhooks

Receive real-time events by registering an HTTPS endpoint. Verify the signature before processing each event. 

POST /v1/webhooks
Content-Type: application/json

{
  "event": "page.published",
  "data": {
    "id": "page_123"
  }
}

API Reference

The API is organized around resources. Requests and responses use JSON.

GET /v1/users/:id

Retrieve a user by their ID. 

curl https://api.example.com/v1/users/user_123 \
  -H "Authorization: Bearer $DOCS_API_KEY"
